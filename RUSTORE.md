# Публикация в RuStore

Краткий чек-лист от собранного APK/AAB до релиза. RuStore допускает внешнюю
оплату на сайте разработчика, поэтому SDK Robokassa внутрь приложения
встраивать **не нужно**.

## 0. Что должно быть готово до релиза

- [x] Проект собирается через `eas build --platform android` (см. `eas.json`).
- [x] Подписка/оплата работает на тестовом режиме Robokassa (см. `server/spaceweb/README.md`).
- [x] У приложения есть свой `applicationId` (Android package). У нас — `com.habittracker.app` в `app.json`.
- [ ] Иконка `assets/icon.png` (1024×1024 PNG, без альфа-канала по периметру).
- [ ] Splash-картинка `assets/splash.png`.
- [ ] Privacy policy URL — RuStore требует страницу с описанием обработки данных. Сделай простую HTML-страницу на том же SpaceWeb (`/privacy.html`).

## 1. Сборка релизного AAB

RuStore принимает AAB (предпочтительно) или APK.

```bash
eas login
eas build --platform android --profile production
```

В `eas.json` профиль `production` уже настроен на сборку `app-bundle` (AAB) с
автоинкрементом `versionCode`. По завершении EAS даст ссылку на скачивание AAB.

> При первой сборке EAS попросит сгенерировать **release keystore** — соглашайся,
> ключ хранится у Expo (можно потом экспортировать). Тот же keystore нужен для
> всех последующих обновлений.

## 2. Кабинет RuStore

1. Зайди на `console.rustore.ru` через VK ID или email.
2. Подтверди статус **самозанятого**: загрузи скан паспорта и справку из ФНС
   о постановке на учёт по НПД (`Мой налог` → раздел "Профиль" → справка о
   статусе самозанятого, выгружается одной кнопкой).
3. Создай новое приложение:
   - Имя: `Дневник привычек` (RU) / `Habit Diary` (EN)
   - Категория: «Образ жизни» или «Здоровье и фитнес»
   - Возрастной рейтинг: 0+
   - Платное/бесплатное: **бесплатное**, потому что подписка идёт через
     внешний сайт.

## 3. Загрузка билда

1. **Сборка** → загрузить AAB → версия (например, `1.0.0`).
2. Указать:
   - **Краткое описание** (до 80 символов): «Трекер привычек с AI-инсайтом дня».
   - **Полное описание**: фичи + что появляется в Premium.
   - **Что нового**: «Первый релиз».
3. **Скриншоты** (минимум 3):
   - 6.5″ телефон — запиши сам или сделай через Android-эмулятор.
   - Обязательно показать: главный экран, экран добавления привычки,
     статистику.
4. **Иконка приложения** 512×512 PNG.
5. **Графический баннер** (Feature Graphic) 1024×500 — RuStore запросит.

## 4. Юридическая часть

1. **Возрастной рейтинг** — заполнить анкету (приложение не содержит контента
   18+, рекламы, азартных игр и т. п. → выйдет 0+).
2. **Политика конфиденциальности** — указать ссылку на `https://your-domain.ru/privacy.html`.
   RuStore проверит, что страница реально открывается. Минимальный текст
   privacy: что собирается анонимный `userId`, что данные хранятся локально,
   что для оплаты используется Robokassa, и контактный email.
3. **Способы монетизации** → выбрать «Платный контент через сайт разработчика»
   и указать ссылку на твою страницу оплаты или политику возвратов.

## 5. На что обращает внимание модерация

- Иконка не должна повторять стоковые иконки Apple/Material.
- В описании нельзя писать «AI-психолог», «лечит депрессию», «диагностирует»
  и т.п. — это медицинские утверждения, требуют лицензии. Достаточно «AI-инсайт
  дня».
- Если Premium-фичи показаны на скриншотах — рядом должна быть упомянута
  цена и периодичность.

## 6. После публикации

- В RuStore появится отдельный **deep-link**: `rustore://app/com.habittracker.app`.
  Можно использовать в маркетинге.
- Для обновления — `eas build --platform android --profile production`, затем
  загрузить новый AAB; `versionCode` инкрементится автоматически.
- Возвраты по подписке RuStore не контролирует (мы платим вне стора), все
  возвраты — через Robokassa, по правилам, описанным на твоей странице
  условий.

## 7. Тестовый трек до публики

В кабинете RuStore рядом с боевым релизом доступен **закрытый тестовый трек** —
загрузи туда отдельный AAB и пригласи себя как тестера по email. Удобно, чтобы
проверить весь флоу оплаты на реальном устройстве, не делая релиз публичным.
