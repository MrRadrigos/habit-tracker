Все реквизиты (ФИО Ерошкин А.А., ИНН 771981325482, телефон, email) уже подставлены.

## Что внутри

- `index.html` — главная: описание продукта, цена, ссылка в RuStore.
- `terms.html` — публичная оферта (заполнена по шаблону Robokassa).
- `privacy.html` — политика конфиденциальности.
- `refund.html` — условия возврата.
- `contacts.html` — реквизиты самозанятого и поддержка.
- `_styles.css` — общий тёмный стиль (имитирует приложение).

## Куда залить на SpaceWeb

Лендинг живёт в **корне домена**, а PHP-скрипты оплаты — рядом в подпапке `pay/`:

```
public_html/
├── index.html        ← из site/
├── terms.html
├── privacy.html
├── refund.html
├── contacts.html
├── _styles.css
└── pay/              ← из server/spaceweb/ (без папки site/)
    ├── pay.php
    ├── result.php
    ├── status.php
    ├── store.php
    ├── config.php    ← создать из config.example.php, заполнить, НЕ коммитить
    ├── store.json    ← {"users":{},"invoices":{}}
    ├── success.html
    ├── fail.html
    └── .htaccess
```

В `app.json` приложения:

```json
"extra": {
  "paymentBaseUrl": "https://amigos29ya.temp.swtest.ru/pay"
}
```

## Что смотрит модерация Robokassa

- Сайт реально открывается, не отдаёт 404/500.

- В контактах указаны ФИО и ИНН самозанятого.
- В оферте прописана цена, периодичность, что входит в подписку.
