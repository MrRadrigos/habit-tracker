# Лендинг и правовые страницы

Минимальный набор HTML-страниц для прохождения модерации Robokassa и RuStore.

## Что внутри

- `index.html` — главная: описание продукта, цена, ссылка в RuStore.
- `terms.html` — публичная оферта.
- `privacy.html` — политика конфиденциальности.
- `refund.html` — условия возврата.
- `contacts.html` — реквизиты самозанятого и поддержка.
- `_styles.css` — общий тёмный стиль (имитирует приложение).

## Что заменить перед публикацией

Открой каждый HTML и через **Find & Replace** замени плейсхолдеры:

| Плейсхолдер | Куда подставить |
|---|---|
| `[ФИО]` / `[ФИО полностью]` | Твоё ФИО как самозанятого |
| `[ИНН]` | Твой ИНН (12 цифр) |
| `[EMAIL]` | Контактный e-mail для поддержки и юр. вопросов |
| `[TELEGRAM_USERNAME]` | Username в Telegram (без `@`); если нет — удали блок |
| `[ДОМЕН]` | Например, `habit-diary.ru` |
| `[ДД.ММ.ГГГГ]` | Дата редакции документа (текущая) |
| `[ССЫЛКА_НА_ПРИЛОЖЕНИЕ_В_RUSTORE]` | Появится после публикации в RuStore. Пока можно поставить `#` |

## Куда залить

Лендинг живёт в **корне домена**, а PHP-скрипты оплаты — рядом, например:

```
public_html/
├── index.html        ← из site/
├── terms.html
├── privacy.html
├── refund.html
├── contacts.html
├── _styles.css
└── pay/              ← из server/spaceweb/ (без папки site/)
    ├── pay.php
    ├── result.php
    ├── status.php
    ├── store.php
    ├── config.php
    ├── store.json
    ├── success.html
    ├── fail.html
    └── .htaccess
```

Тогда у тебя получится:
- `https://твой-домен.ru/` — лендинг
- `https://твой-домен.ru/privacy.html` — для модерации Robokassa и RuStore
- `https://твой-домен.ru/pay/pay.php?userId=...` — точка входа оплаты

И в `app.json` приложения:

```json
"extra": {
  "paymentBaseUrl": "https://твой-домен.ru/pay"
}
```

## На что смотрит модерация Robokassa

- Сайт реально открывается, не отдаёт 404/500.
- На главной видно, что вы продаёте, и сколько это стоит.
- Есть прямые ссылки на оферту, политику конфиденциальности, условия возврата, контакты — обычно в шапке или подвале.
- В контактах указаны ФИО и ИНН самозанятого.
- В оферте прописана цена, периодичность, что входит в подписку.

## На что смотрит модерация RuStore

- Privacy policy открывается по той же ссылке, что указана в карточке приложения в RuStore Console.
- В описании в RuStore цена и состав Premium совпадают с тем, что на сайте.
