1. Кто оператор данных

Оператор персональных данных — самозанятый [ФИО полностью], ИНН [ИНН], контактный e-mail [EMAIL].

2. Какие данные обрабатываются

Приложение «Дневник привычек» хранит на устройстве Пользователя:

  • Список привычек, отметки выполнения, статистику и пользовательские настройки.
  • Анонимный идентификатор установки (UUID), генерируемый при первом запуске.

На сервер Исполнителя передаются только данные, необходимые для оплаты подписки и определения её статуса:

  • Анонимный идентификатор установки (UUID).
  • Сумма и идентификатор счёта Robokassa.
  • Дата и время оплаты, дата окончания текущей подписки.

Имя пользователя, привычки и любые другие пользовательские записи на сервер не передаются и не покидают устройство.

3. Какие данные передают сторонние сервисы

Платёж принимает ООО «РОБОКАССА» в соответствии с собственной политикой. Карточные данные Пользователя ни в каком виде не попадают на серверы Исполнителя.

Для генерации AI-инсайтов краткая обезличенная статистика (название привычки, стрик, процент выполнения за неделю) передаётся в OpenAI через сервер-прокси Исполнителя. Эти данные не привязаны к личности Пользователя.

4. Цели обработки

  • Активация и продление платной подписки.
  • Восстановление доступа к подписке на новом устройстве.
  • Поддержка пользователей по их обращениям.

5. Срок хранения и удаление

Данные о платежах и подписке хранятся на сервере Исполнителя в течение срока, предусмотренного законодательством РФ для бухгалтерских документов (не менее 5 лет). По письменному запросу Пользователя на адрес [EMAIL] идентификатор установки и связанные с ним записи могут быть удалены, если это не нарушает требования законодательства.

Пользователь вправе запросить сведения об обрабатываемых о нём данных, потребовать их уточнения или удаления, направив запрос на электронную почту [EMAIL].
